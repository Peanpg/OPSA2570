# วัดโหลดหม้อแปลงน้ำพอง

แอพสำหรับทีมวัดโหลด 43 เครื่อง 12 ตำบล ใช้โครงสร้าง Next.js + Neon Postgres สำหรับ GitHub / Vercel เช่นเดียวกับแอพเดิม

## การใช้งาน

- เปิดหน้าแผนที่ หรือรายการ กรองตำบล / PEA / Location / ฟีดเดอร์ / เวลา Peak
- หน้าแรก “เวลา Peak” แสดงชื่อเครื่องทั้งหมดแยก 5 ช่วงเวลา กรองตำบลและติ๊กวัดแล้วได้จากหน้าเดียว
- ตัวกรองเวลา Peak อยู่ใต้ช่องตำบลบนแผนที่ ติ๊กได้หลายช่วงพร้อมกัน ใช้ร่วมกับรายการและหน้าตารางเวลา มีเลือกทั้งหมด/ล้าง ถ้าไม่เลือกเวลาเลยจะไม่แสดงจุดงาน หมุดมิเตอร์ของเครื่องที่ถูกกรองออกจะหายไปด้วย
- ติ๊ก “วัดแล้ว” บันทึกส่วนกลางทันที ไม่ต้องกรอกชื่อทีม ชื่อผู้สำรวจ หรือผลวัด
- เอาติ๊กออกเพื่อยกเลิกสถานะ มีหน้าต่างยืนยันก่อนยกเลิก
- ทีมอื่นเห็นผลในรอบซิงก์ปกติประมาณ 3 วินาทีเมื่อหน้าเว็บเปิดอยู่ ขึ้นกับเครือข่าย ไม่ใช่ระบบเรียลไทม์แบบ WebSocket
- ดูรายงานตามตำบลและเวลา Peak กดแถวตำบลหรือเวลาเพื่อเปิดรายการนั้น
- ตำแหน่งมือถือขอสิทธิ์เฉพาะเมื่อกดปุ่ม ไม่แชร์ GPS ให้ผู้อื่นในแอพเวอร์ชันนี้ ปุ่มกรอบเล็กใช้เปิด/ปิดเลื่อนตามตำแหน่ง ไม่มีการซูมอัตโนมัติจากการอัปเดตสถานะ

## ติดตั้งและรัน

ใช้ Node.js ตาม engines ใน package.json จากนั้น `npm ci` และ `npm run dev -- --port 3100`

ตั้งค่า DATABASE_URL ใน .env.local (ดูรูปแบบใน .env.example) ก่อนทดสอบการบันทึกร่วมกัน ไม่ต้องมีข้อมูลลับใน GitHub

ทดสอบ: `node scripts/test-status.mjs`, `node scripts/test-measurement-sites.mjs` และ `npm run build`

## GitHub / Vercel

1. อัปโหลดไฟล์ภายในโฟลเดอร์นี้ที่ root ของ repository ให้ package.json และ app อยู่หน้าหลัก ไม่อัปโหลด node_modules หรือ .next
2. Import repository ใน Vercel เลือก Next.js ไม่แก้ Output Directory
3. เชื่อม Neon หรือใช้ฐานเดิมที่ได้รับอนุญาต ตั้ง DATABASE_URL สำหรับ Production (และ Preview ถ้าใช้)
4. Deploy ถ้าเพิ่มตัวแปรหลัง Deploy แล้วให้ Redeploy อีกครั้ง

แอพสร้างตาราง `namphong_load_campaign_2570` อัตโนมัติเมื่อมีการเรียก API ไม่อ่านหรือเขียนตารางสถานะสำรวจโคมไฟ / มิเตอร์เดิม และไม่มี DELETE API ที่ลบจุดหม้อแปลง

มีการตรวจ revision เมื่อหลายคนกดชนกัน ถ้าติ๊กเป็นผลเดียวกันจะสำเร็จอย่างปลอดภัย ถ้าสถานะขัดกันจะปฏิเสธการเขียนทับแล้วส่งสถานะล่าสุดให้ตรวจสอบ จุดที่ยกเลิกยังเก็บแถวและ revision เพื่อกันคำขอเก่าทับสถานะใหม่

ถ้าฐานข้อมูลหรือเครือข่ายไม่พร้อม จะแสดงคำเตือนและไม่อ้างว่าบันทึกสำเร็จ ไม่เก็บสถานะวัดแล้วเฉพาะเครื่องเป็นข้อมูลร่วมปลอม และไม่บันทึกงานแบบออฟไลน์

## สิทธิ์และข้อมูล

เวอร์ชันนี้ไม่มีหน้า login เช่นเดียวกับรุ่นที่ขอไว้เดิม ทุกคนที่เข้าถึง URL ได้จะอ่านพิกัดและเปลี่ยนสถานะได้ ไม่มีการบันทึกตัวตนผู้กด มีเพียงวันเวลาและ revision จึงควรส่งลิงก์เฉพาะผู้ที่อนุญาต

ข้อมูลเป้าหมาย 43 เครื่องจาก DB_OPSA70 ที่ส่งออกวันที่ 6 พ.ย. 2569 พิกัดจับคู่จาก CSV พื้นที่น้ำพอง รหัส PEA ตรงกันครบทั้งหมด ค่าโหลด / แรงดัน / เวลา Peak เป็น snapshot OPSA Map ที่รวบรวมวันที่ 9 พ.ย. 2569 ไม่ใช่ผลวัดภาคสนามใหม่ ไม่ดึงเว็บ PEA อัตโนมัติ และไม่แสดงเดือน Peak ตามที่ขอ

ตำบลจับคู่ข้อมูลเดิมและสถานที่ ผู้ใช้ยืนยัน 4 เครื่องในตำบลหนองกุงแล้ว การแสดงแผนที่ใช้ OpenStreetMap ต้องมีอินเทอร์เน็ต การใช้ GPS บนมือถือควรเปิดผ่าน HTTPS ของ Vercel

## จุดไปวัดมิเตอร์และปัญหาหม้อแปลง

มีจุดไปวัดมิเตอร์หนึ่งจุดครบทั้ง 43 เครื่องใน `app/measurement-sites.json` รวม 43 จุด: 24 จุดแรงดันตกต่ำกว่า 200 V และอีก 19 จุดแรงดันตั้งแต่ 200 V ขึ้นไปแสดงว่า “แรงดันไม่ตก” ทุกจุดมีพิกัด เฟส ค่าแรงดัน และปุ่มนำทาง ตามข้อมูล GIS วันที่ 9 พ.ย. 2569

หน้ารายละเอียดแสดง “ปัญหาหม้อแปลง” จากรายงาน DB_OPSA70 ที่ส่งออก 6 พ.ย. 2569 ครบ 43 เครื่อง: โหลด/เฟสมากกว่า 100% จำนวน 27 เครื่อง และแรงดันปลายสายน้อยกว่า 200 V จำนวน 16 เครื่อง ปัญหาตามรายงานกับสถานะแรงดันมิเตอร์เป็นคนละข้อมูลและคนละ snapshot การที่มิเตอร์แรงดันไม่ตกไม่ได้หมายความว่าหม้อแปลงไม่มีปัญหาโหลดหรือโหลดเฟส

พิกัดอ่านจาก geometry ของชั้นข้อมูล DS_LowVoltageMeter (PEA_QUERY/MapServer/13, outSR=4326) โดยตรง เฟสต้องตรงกับทั้ง GIS และตารางแรงดัน OPSA.METERRESULT จุดที่เลือกใช้มิเตอร์เฟสเดียว A/B/C เพื่อระบุเฟสที่จะไปวัดได้ชัดเจน ไม่ใช้พิกัดหม้อแปลงหรือพิกัดเคอร์เซอร์แทนมิเตอร์ และไม่เก็บชื่อหรือที่อยู่ผู้ใช้ไฟฟ้า

`meterConfirmed` ยืนยันรหัส พิกัด เฟส และค่าแรงดันของมิเตอร์ ทั้งที่ตกและไม่ตก ส่วน `terminalConfirmed` แยกตรวจแนวสาย GIS ชั้น DS_LVConductor (24) ถ้าเป็น true หมายถึงพบปลายเส้นที่เชื่อมต่อเพียงเส้นเดียวในเฟสเดียวกันภายใน 5 เมตรจากมิเตอร์ ไม่ใช่การยืนยันภาคสนามหรือการพิสูจน์ระยะทางเดินสายไกลที่สุด การเลือกใช้ปลายแขนงที่ตรวจได้ก่อน แล้วพิจารณาระยะทางตรงจากหม้อแปลง ชุดปัจจุบันตรวจปลายแขนงตามเกณฑ์นี้ได้ 22 จุด อีก 21 จุดมีพิกัดและเฟสแน่นอน แต่ยังไม่ยืนยันปลายแขนงและมีข้อความกำกับในแอพ

แอพแสดงหมุดมิเตอร์เฉพาะหม้อแปลงที่เลือก และแสดงเฟส แรงดัน พิกัด พร้อมปุ่มนำทางในหัวข้อพับ “จุดไปวัดมิเตอร์” เส้นประเชื่อมตำแหน่งเป็นเพียงตัวช่วยดูแผนที่ ไม่ใช่แนวสายไฟ ปุ่มนำทางด้านบนยังพาไปหม้อแปลง ปุ่มนำทางในหัวข้อมิเตอร์จึงจะพาไปมิเตอร์

ค่าแรงดันใช้ค่าที่ GIS แสดงตามผู้ใช้ยืนยัน ไม่อ้างว่าเป็นค่า Peak ของมิเตอร์ ส่วนเวลา Peak และแรงดันต่ำสุด Peak ของหม้อแปลงยังแสดงแยกกัน เป็น snapshot ไม่ใช่ข้อมูลสด
